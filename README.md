# Landing Page

A modern, responsive, and accessibility-focused landing page implementation built using semantic HTML5, custom CSS, and Vanilla JavaScript based on the provided design specifications.

- [View Live Project](https://naimeshrao.github.io/ui-prototype-challenge/)

---

## Features

- Semantic HTML5 structure
- Custom CSS architecture with BEM methodology
- Fully responsive across all screen sizes
- Cross-browser compatibility
- WCAG 2.2 AA accessibility support
- Keyboard and screen reader accessibility
- Reusable animations and interactive components
- Motion accessibility with `prefers-reduced-motion`
- Animation on scroll with stagger effect
- Optimized images for better performance, Defer javascript

---

## Included Sections

- Hero section with dual-axis slider
- Participating schools section dual slider (ltr/rtl) sling animation
- Exhibition highlights slider with arrows
