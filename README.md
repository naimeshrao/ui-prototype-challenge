# Responsive Landing Page

Responsive and accessible landing page implementation based on the provided design specifications using semantic HTML5, custom CSS, and JavaScript.

## Features

- Semantic HTML5 structure
- Custom CSS with BEM methodology
- Fully responsive layout
- Cross-browser compatibility
- WCAG 2.2 AA accessibility support
- Keyboard and screen reader accessibility
- Accessible sliders and animations

## Sections

- Hero section with dual-axis slider
- Responsive school cards section
- Exhibition highlights slider

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Browser Support

Compatible with latest versions of:

- Chrome
- Firefox
- Safari
- Edge
- iOS & Android browsers

## Notes

- Fully responsive across devices
- Accessibility-focused implementation
- Animations respect user motion preferences
